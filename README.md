
# 💳 Credit Card Fraud Detection & Analysis | Tableau

An interactive Tableau project designed to explore credit card
transactions, identify fraud patterns, and understand customer risk
through three dashboards.

## 📊 Project Dashboards

### 1. Transaction Analysis Dashboard

Explore transaction activity and transaction patterns.

Compare transaction amounts across available categories and
dimensions.

Use interactive filters to focus on relevant transaction details.

### 2. Fraud Analysis Dashboard

Track key fraud metrics, including total fraud transactions, total
fraud amount, average fraud score, fraud rate, and maximum fraud
score.

Analyze monthly fraud trends.

Compare fraud transaction counts by location.

Explore fraud distribution by merchant category.

Compare fraud and legitimate transactions across time periods.

Examine the relationship between transaction amount and fraud score.

### 3. Customer & Risk Analysis Dashboard

Analyze customers by age group, gender, and occupation.

Explore annual income and credit score patterns.

Compare customer risk levels and fraud scores.

Use customer and risk attributes to investigate patterns in the
dataset.

🛠️ Tools & Technologies

Tableau Public --- dashboard development and data visualization

Data Analysis --- transaction, fraud, and customer-risk analysis

✨ Key Features

Three interactive dashboards

KPI cards for quick metric summaries

Charts for trend, category, location, transaction, and risk analysis

Filters/slicers to explore data by relevant dimensions

Visual comparison of fraud and legitimate transactions

🎯 Project Objective

The goal of this project is to make transaction and fraud data easier to
explore, highlight patterns in fraudulent activity, and support a
clearer understanding of customer and transaction risk.
